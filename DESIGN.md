# Alwankhat — Design System

## Modes
- **Experience** for the portfolio/gallery — the artwork leads from the first viewport; the interface recedes
- **Operate** for shop + checkout — clean, scannable, trust-building

## Palette
| Token | Hex | Use |
|---|---|---|
| Baby pink | `#F8C8DC` | backgrounds, soft fills |
| Rose pink | `#E8A0BF` | accents, buttons, links |
| Dusty rose | `#B76E8F` | secondary text, borders |
| Cream | `#FFFDFC` | page background |
| Rose ink | `#5C4A52` | body text, headings |
| Gold | `#C9A227` | sparse luxury accent (optional) |

Soft pink gradient washes only; never purple, never blue.

## Typography
- **Logo/display:** italic script — Pinyon Script / Parisienne / Great Vibes
- **Body:** elegant serif — Cormorant / Lora (paired with a clean sans for UI labels)
- Avoid: Inter, system defaults, all-caps-heavy corporate type

## Materials & texture
- Paper, ink, canvas, subtle gold flecks
- Hairline dividers, generous whitespace, soft radii
- Image-forward: large artwork photography, thin frames

## Components
- Buttons: pill, rose-pink fill, cream text, gentle hover lift
- Cards: minimal — image + title + price, no nested-card clutter
- Sold badge: muted dusty rose, elegant not alarming

## Motion
- Gentle, spring-based; slow fades and scale on hover
- No bounce/elastic, no heavy scroll-jacking
- Ease-out on enter, ease-in only on exit (per Emil Kowalski)

## Anti-patterns
- No purple-to-blue gradients, no gray text on colored backgrounds, no pure black
- No cards-in-cards, no oversized icons-tile-above-heading layout
